# Catálogo de Productos - Semanas 5 y 6


## Descripción

Aplicación desarrollada en Python para integrar los contenidos de
las semanas 5 y 6:

- Colecciones list, dict y set.
- Operaciones CRUD.
- Interfaz gráfica con Flet.
- Manejo de eventos.
- Validación de datos.
- Programación orientada a objetos.
